# 🛡️ Lendas da Algoritmia

Um RPG 2D educativo e interativo desenvolvido para explorar, ensinar e praticar conceitos de programação e lógica de forma divertida!

🔗 **Jogue online aqui:** [https://lendas-da-algoritmia.web.app/](https://lendas-da-algoritmia.web.app/)

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web modernas e ferramentas de suporte:

* **JavaScript (Vanilla):** Lógica principal do jogo, manipulação do DOM, gestão de estados e mecânicas de RPG.
* **HTML5 & CSS3:** Estruturação das telas e estilização da interface visual, menus e elementos interativos.
* **Git & GitHub:** Controlo de versão do código-fonte e armazenamento do repositório.
* **Firebase Hosting:** Hospedagem rápida e segura para colocar a aplicação web online.

---

## 💡 O que Aprendi e Desenvolvi

O desenvolvimento do *Lendas da Algoritmia* proporcionou um excelente crescimento prático nas seguintes áreas:

1. **Arquitetura de Jogos em JavaScript:** Estruturação de loops de jogo, gestão de eventos de teclado/rato e renderização dinâmica de elementos visuais no ecossistema web.
2. **Organização de Código:** Divisão eficiente de responsabilidades entre ficheiros para manter a manutenibilidade e escalabilidade do projeto.
3. **Deploy e Publicação:** Configuração e subida de uma aplicação web estática utilizando a CLI do Firebase, integrando o fluxo de desenvolvimento local com o ambiente de produção.
4. **Controlo de Versão Avançado:** Resolução de fluxos com o Git, desde a inicialização de repositórios locais (`git init`, `git commit`) até à sincronização remota com o GitHub (`git push`).
